# 漫剧笔搭子

PRJ001 的本地对话式短片创作工具。从一句创意开始，依次生成并确认创作简报、故事、剧本、角色/场景/道具设定、分镜，最后为每个镜头生成 Seedream 5.0 Lite 首帧图片提示词和 MiniMax H3 视频提示词。

## 当前能力

- 多个独立的动漫或真人短片项目，支持五种常见画幅。
- DeepSeek 官方 API 流式生成；生产模型可选择 `deepseek-flash` 或 `deepseek-v4-pro`。
- 内容手工保存、确认锁定、重新编辑和下游“需要重新生成”状态。
- 分镜提示词批量生成、逐镜进度、失败镜头重试和停止生成。
- 最终提示词追加版本、任意版本逐行比较和恢复为新版本。
- 每镜头一个 Markdown 或纯文本文件，统一打包为 ZIP。
- API Key 仅由本地 Node 服务读取，并使用 Windows 当前用户 DPAPI 加密保存。

项目数据库和版本历史保存在本机。执行 AI 生成时，完成当前任务所需的创作内容会发送给 DeepSeek；请同时阅读 DeepSeek 的隐私政策和开放平台条款。

## 本地命令

- `npm ci`：按锁文件安装开源依赖。
- `npm run check`：执行 TypeScript 静态检查。
- `npm test`：运行单元、集成、合同和界面测试；模型调用均由假模型替代。
- `npm run build`：构建前端与本地服务。
- `npm run test:e2e`：使用临时本机服务和假模型运行浏览器闭环测试。
- `npm run start`：启动已构建的本地应用。

生产运行使用独立的 `creation-v2.db`，不会读取或迁移旧 REQ-010 测试数据库。
